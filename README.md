# studyhive
A multi-page study guide web project designed to help students improve focus, planning, and motivation.
The website includes a Pomodoro timer, study methods, motivation tips, planners, and a collection of free study resources.
## Features
- Pomodoro timer for focused study sessions
- Study methods and productivity techniques
- Motivation content for students
- Planning tools and study hacks
- Free learning resources
- Contact page for feedback
## Design & Development
This project was fully designed and developed by me, including:
- Frontend development using HTML, CSS, and JavaScript
- Custom logo design created with Adobe Illustrator
- Image editing and optimization using Adobe Photoshop
- UI/UX planning focused on student productivity and usability
